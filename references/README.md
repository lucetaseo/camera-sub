# 레퍼런스 사진 폴더

장면별 하위 폴더를 만들고 **사용 허락을 받은 사진**만 넣으세요.

```
references/
  landscape/     풍경
  beach/         바다
  city/          도시/거리
  architecture/  건물/대칭
  portrait/      인물 클로즈업
```

- 직접 찍은 사진, Unsplash/Pexels 등 무료 라이선스 사진, 허락받은 사진을 쓰세요.
- 인스타그램 등에서 남의 사진을 내려받아 쓰는 것은 이용약관·저작권 위반이 될 수 있습니다.
  다른 계정의 구도를 참고하고 싶다면 사진을 저장하지 말고, 구도를 보고 비슷하게 직접 찍은 사진을 넣으세요.
- 이 폴더의 사진은 git 에 올라가지 않습니다 (`.gitignore`).
- 장면당 최소 10장 이상, 인물이 한 명 또렷하게 보이는 사진이 좋습니다.
